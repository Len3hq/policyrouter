# @policyrouter/policy

This package is the single source of truth for how PolicyRouter talks to TapeOut circuits. It holds the TapeOut addresses and the pin packing. Template truth tables, simulation and receipt hashing are added in later phases.

## Phase 0 findings (checked 2026-10-01)

Every item below was checked against X Layer mainnet (chain 196) by `contracts/test/fork/TapeOutSpike.t.sol`, which passes on a fork:

```bash
cd contracts && forge test --fork-url https://rpc.xlayer.tech -vv
```

### Functions

| Step | Call |
| --- | --- |
| Create processor | `factory.createCPU(name, symbol, story, transistorSupply, mintPrice)`, paying `deployFee()` → `(transistors, circuits)` |
| Mint transistors | `transistors.mint(0, amount)`, paying `mintPrice * amount + factory.protocolFee()` |
| Tape out | `circuits.tapeout(netlist, nIn, nOut)`, paying `TAPEOUT_FEE()`; burns one transistor per gate from the caller; returns the circuit ID (an ERC-721 owned by the caller) |
| Evaluate | `circuits.eval(circuitId, inputBytes) → outputBytes` (`view`, so free through `eth_call`) |
| Creator payout | Mint proceeds accrue to `transistors.owed(creator)`; the creator calls `withdraw()` |

A tape-out sends the netlist bytes straight to the contract, so circuits can be generated by script. The canvas is not required.

### Fees (on chain, 2026-10-01)

| Fee | Amount | When |
| --- | --- | --- |
| `deployFee` | 0.0066 OKB | Once, when the processor is created |
| `protocolFee` | 0.00066 OKB | Per `mint` call, on top of the mint price |
| `TAPEOUT_FEE` | 0.0013 OKB | Per tape-out |

### Answers to the spec's open questions

| Question | Answer |
| --- | --- |
| How does `eval()` pack bits? | Pin `i` is bit `i % 8` of byte `i >> 3`: least significant bit first, little-endian across bytes. Our 6 input pins fit in one byte, so input value `v` is the byte `v`. Outputs are the **last** `nOut` signals of the netlist, packed the same way. Proven on chain by `test_evalPinPacking` |
| Transistor token standard | ERC-1155, token ID 0 (`supportsInterface(0xd9b67a26)` returns true, both on TapeID's live contract and on a freshly created one). So there are no Uniswap pools; resale happens on TapeOut's market or NFT marketplaces |
| Does TapeOut take a cut of mint proceeds? | No. The creator is owed the full `mintPrice * amount`. TapeOut charges its `protocolFee` to the minter on top (`test_mintPaysCreatorInFull`) |
| Can a contract be the processor's creator? | Yes. A contract that calls `createCPU` in its constructor becomes `creator()` (`test_contractCanBeCreator`). The Treasury contract option is open |
| Do latches keep state between `eval()` calls? | No. `eval` is `view`, so it can never write state. Our policies are combinational (`nState = 0`) anyway |
| Can transistors be priced in USDT? | No. `createCPU` takes a single `mintPrice` paid as `msg.value`, so the price is in OKB only |
| Netlist format | Signal 0 is constant 0, signal 1 is constant 1, signals `2 .. 2+nIn-1` are the input pins, then one new signal per element. NAND = `0x00 a:u24 b:u24`; LATCH = `0x01 d:u24` |
